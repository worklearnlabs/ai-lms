# Adaptive Learning System

This repository contains the Adaptive Learning System, a web-based platform built for AI enthusiasts and professionals. The project is located in the `my-app` directory.

## Getting Started

All commands should be run from the `my-app` directory:

```bash
cd my-app
npm install
npm run dev
```

For more detailed documentation, please see [my-app/README.md](my-app/README.md).

## Project Structure

The main project is in the `my-app` directory. This root directory exists for historical reasons but all development should happen within `my-app`.
